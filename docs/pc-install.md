# PC(Windows) 설치 안내 — Apple Music 웹용 가사 보조

Windows의 **Chrome 또는 Edge**에서 [Apple Music 웹](https://music.apple.com)으로 음악을 들을 때, 브라우저 옆 **사이드 패널**에 현재 곡의 원문·한글 발음·한국어 번역 가사를 자동 싱크로 보여 주는 **확장 프로그램**이다(개인 사용, docs/plan.md D-36).
iPhone 앱과 같은 core 로직을 쓰므로 곡 식별·저장본 우선·번역 정책·편집·수동 싱크·번역 묶음·백업 규칙이 같다.

> **확인 상태(2026-10-06)**: 자동 검사(core 해석·타입·빌드)와 가짜 재생기 데모 화면, Windows 보안 저장소 도우미 자동 시험은 이 PC에서 통과했다. **실제 브라우저에 설치해 Apple Music 웹과 연동한 확인은 아직 0건**이다(MV-PC-01~03).

## 1. 준비물
- Windows 10/11, **Chrome 116 이상 또는 Edge 116 이상**
- Apple Music **구독 계정**(로그인하지 않으면 30초 미리듣기만 재생되어, 곡의 몇 초인지 알 수 없으므로 가사를 맞추지 않는다)
- 빌드할 때만: Node.js(이 저장소의 `.tmp/node`에 받아 둔 휴대용 Node도 됨)

## 2. 빌드
```powershell
cd "E:\ai data\노래가사앱(로컬)\apps\pc-extension"
npm ci          # 처음 한 번
npm run build   # → apps\pc-extension\dist 생성
```
`npm run check`(저장소 루트)도 `pc` 단계에서 같은 빌드를 만든다.

## 3. 브라우저에 설치(압축해제된 확장 프로그램)
1. 주소창에 `chrome://extensions`(Edge는 `edge://extensions`) 입력
2. 오른쪽 위(Edge는 왼쪽) **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → `E:\ai data\노래가사앱(로컬)\apps\pc-extension\dist` 폴더 선택
4. 확장 프로그램 ID가 **`ggohabnpccimkbiclbehihpgiocjedhd`** 인지 확인(매니페스트의 `key`로 고정 — 보안 저장소 도우미가 이 ID만 허용한다)
5. 도구 모음의 퍼즐 아이콘에서 "가사 보조"를 고정하면 편하다

코드를 고쳐 다시 빌드한 뒤에는 확장 프로그램 페이지에서 **새로고침(↻)** 을 누르고, 열려 있던 Apple Music 탭도 새로고침한다.

## 4. 사용
1. music.apple.com 을 열고 로그인
2. 도구 모음의 **가사 보조** 아이콘 → 오른쪽에 사이드 패널이 열린다
3. 웹 플레이어에서 곡을 재생하면 패널에 가사가 맞춰 나온다
   - 줄을 누르면 그 위치로 이동, 아래 막대로 재생·일시정지·±10초·이전/다음
   - 탭 위 창 아이콘(□)을 누르면 **따로 띄운 창**으로 옮겨진다(다른 모니터에 둘 수 있음). 사이드 패널과 창은 동시에 열지 않는다(같은 저장소를 한 곳에서만 고치기 위해).
4. **대기열** 탭: 웹 플레이어에서 플레이리스트·앨범을 재생하면 그 곡들이 보인다. "가사 원문 일괄 받기", "번역 한꺼번에 넣기"(번역 묶음 파일 — 다운로드 폴더에 저장)가 iPhone 플레이리스트 탭과 같다.
5. **설정** 탭: 전체 싱크 보정, AI 제공자, API 키, 자동 번역, 백업

### iPhone 데이터 옮기기
iPhone 앱 설정 › 백업 › **백업 파일 만들기** → 파일을 PC로 옮김 → PC 패널 설정 › **백업 가져오기**. 같은 곡을 웹에서 재생하면 내 번역·발음·싱크 기록이 바로 보이고, 가사·AI를 다시 요청하지 않는다(같은 Apple Music 스토어 ID로 연결). 반대로 PC에서 만든 백업을 iPhone에서 가져올 수도 있다.

## 5. AI 번역을 쓸 때: Windows 보안 저장소 도우미 설치(한 번)
확장 프로그램 저장소에는 API 키를 두지 않는다(불변조건 8). 대신 작은 도우미가 키를 **Windows DPAPI**(현재 사용자 범위)로 암호화해 `%LOCALAPPDATA%\LyricsCompanion\secrets`에 보관한다.

```powershell
cd "E:\ai data\노래가사앱(로컬)\apps\pc-extension\native-host"
powershell -ExecutionPolicy Bypass -File .\install.ps1
```
- 하는 일: 도우미 파일을 `%LOCALAPPDATA%\LyricsCompanion\native-host`로 복사, 현재 사용자 레지스트리(HKCU)에 Chrome·Edge용 네이티브 메시징 호스트 `com.lyrics_companion.secret_store` 등록. 관리자 권한·전역 설정 변경 없음.
- 설치 후 **브라우저를 완전히 닫았다가 다시 열기** → 설정 › API 키에 "설치됨" 표시 → 키 붙여넣기 → 키 저장(화면에는 끝 4자리만).
- AI 제공자 설정을 저장할 때 브라우저가 **그 주소 접근 허용**을 묻는다. 허용해야 번역 요청이 나간다.
- 제거: `powershell -ExecutionPolicy Bypass -File .\uninstall.ps1` (저장된 키까지 지우려면 `-RemoveKeys`)

## 6. 데이터 위치·주의
| 데이터 | 위치 | 비고 |
|---|---|---|
| 가사·번역·발음·싱크 보정 | 브라우저 프로필 안 확장 프로그램 IndexedDB(SQLite 파일 통째) | 확장 프로그램을 **제거하면 함께 지워진다** → 먼저 백업 |
| API 키 | `%LOCALAPPDATA%\LyricsCompanion\secrets\*.bin`(DPAPI 암호문) | 다른 Windows 사용자·다른 PC에서는 풀 수 없다 |
| 백업·원문 TXT·번역 묶음 | 브라우저 다운로드 폴더 | 사용자가 직접 관리 |

- Chrome과 Edge는 **저장소가 따로**다(한쪽에서 저장한 번역이 다른 쪽에 보이지 않음). 옮기려면 백업 파일을 쓴다.
- 확장 프로그램은 Apple Music 페이지에서 **지금 재생·대기열 값만** 읽고, 재생 제어 명령 외에는 페이지에 아무것도 보내지 않는다. Apple 계정 정보·토큰은 읽지 않는다.

## 7. 문제 해결
| 증상 | 확인 |
|---|---|
| 패널에 "Apple Music 웹과 연결"만 보임 | Apple Music 탭을 새로고침(F5). 확장 프로그램을 설치·업데이트하기 전에 열린 탭은 처음 한 번 새로고침이 필요할 수 있다. 패널의 "다시 연결" |
| "재생 위치 모름" + 위치를 읽지 못한다는 안내 | Apple Music 웹에 로그인(구독)했는지(미리듣기는 곡 위치를 알 수 없다) |
| "다른 창에서 이미 열려 있습니다" | 사이드 패널 또는 따로 띄운 창 중 하나를 닫고 다시 열기 |
| API 키 "설치되지 않음" | install.ps1 실행 후 브라우저 **완전 종료**(작업 표시줄 아이콘 포함) 후 다시 실행. 확장 프로그램 ID가 4번 값과 같은지 |
| 번역 묶음 가져오기에서 "곡을 찾지 못함"(iPhone에서 만든 파일) | 파일의 곡 표시는 iPhone 저장소 기준이라, PC에 그 곡의 가사 원문이 있어야 한다. ① 설정 › 백업 가져오기로 iPhone 백업을 먼저 가져오기(가장 정확) 또는 ② 그 곡들을 Apple Music 웹에서 재생하고 대기열 탭 "가사 원문 일괄 받기" → 같은 파일 다시 가져오기. 원문이 글자 그대로 같은 곡은 "원문으로 찾음"으로 연결된다 |
| 가사가 늦거나 빠름 | 지금 재생의 −/+(곡별) 또는 설정 › 가사 싱크(전체) |
