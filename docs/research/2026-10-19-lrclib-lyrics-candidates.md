# LRCLIB 가사 후보 실태 조사 (2026-10-19, D-43)

목적: 가사 우선순위(곡 일치 → 싱크 → 원문 → 한국어 뜻 → 발음)를 정할 때 실제 LRCLIB 레코드가 어떤 모양인지 확인.
방법: 사용자 PC의 Linux 작업 공간에서 `https://lrclib.net/api/search`를 순차 호출(식별 헤더, 0.6초 간격, 503은 1.5초 뒤 재시도)하고
줄별 글자 체계(가나·한자 / 한글 / 라틴)만 세었다. **가사 본문은 저장하지 않았다**(아래는 통계와 레코드 ID만).

## 참고
- 검색 중 503(과부하)이 여러 번 나옴(D-33 재시도 근거와 같음).
- 한국어 뜻·발음이 든 레코드는 드물다. 자동 조회에서 이 기준이 실제로 갈리는 경우는 적고, 주로 싱크·원문 기준이 결과를 바꾼다.
